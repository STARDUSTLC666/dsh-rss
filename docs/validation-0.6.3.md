# 0.6.3 · DSH alpha.5 网页验收

宿主为公开 npm `@deepseek-ai/dsh@0.2.1-alpha.5`，Windows Node 24，系统 Chrome 无头浏览器，使用隔离 profile。

- 119 项自动测试通过。
- 实际打开推荐来源目录并搜索，预览嵌套 OPML 分类后明确导入；编辑名称和导出文件均读取同一份订阅配置。导入不会自动抓取全部来源。
- 英文标题曾在 390px 窗口的双列设置布局中被截断；修复后 RSS 所在设置页改用顶部换行导航，正文占用完整可用列，标题、按钮和下拉框可读。关闭 RSS 面板后该导航样式不影响其他设置页。
- 中文与英文 UI 操作通过，原始来源名称和用户分类保持原文；错误与空列表有明确提示。

本轮不重测真实外部网站，也不声称没有 VPN 的网络验收通过；网络可用性仍由用户的实际连接决定。原生桌面窗口未操作。
