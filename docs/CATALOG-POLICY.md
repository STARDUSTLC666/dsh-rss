# 推荐订阅源收录规则

[English](CATALOG-POLICY.en.md) · [使用流程](USAGE.md)

推荐目录欢迎独立出版物，包括英文科技、AI、软件与信息安全媒体。是否独立经营、访问量或是否付费合作不作为收录前提；条目须适合目录主题，提供可核对的官方网站与由出版者确认的 RSS/Atom 地址。

收录免费、非独家。出版者可以把收录范围限定为名称、官方网站及订阅地址；分类、语言或简介等附加字段也只在获准范围内采用。通过本仓库 issue 提交或撤回申请；核对发布者身份和具体地址后，维护者在后续目录版本中更新或移除。更新目录不能撤回他人已安装的旧版本，也不会自动删除用户自己保存的订阅。

**咨询或提供主页链接不构成文章使用授权。** 先确认出版者提出的收录条件，再按约定范围登记条目；RSS 地址可以核对其官网公开的订阅链接，不猜测或生成地址。地址和格式检查不代表已订阅，也不扩大内容使用权。

目录条目的许可仅限约定的登记信息，不是文章或图片的转载、改写、摘要、翻译、模型训练或再许可授权。本插件的 MIT 许可证只覆盖插件代码；不会把第三方内容变成 MIT 内容。目录不要求出版者授予上述内容使用权；若另行请求这些用途，须分别确认适用权利与条件。

浏览目录不会订阅或批量抓取。用户主动选择“预览并检查”或“订阅”才请求所选 feed；订阅是用户自己的选择，不能由目录条目推导出版者已批准后续内容用途。已有订阅也不会因新目录条目被自动改名、改分类或替换地址。

issue #4：维护者接受出版者提出的免费、非独家、仅登记名称和官方链接、可申请移除的条件。条目使用 Joho no Todai、出版者更正的主页 https://joho-todai.com/ 及英文页面公开链接的 https://joho-todai.com/en/rss/；不附文章摘要或图片。只核对了 RSS 格式与语言，未自动订阅或建立文章档案。
